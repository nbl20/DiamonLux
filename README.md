## 👕 Daimon Lux – Achat / Revente de vêtements de luxe

Projet réalisé dans le cadre de mon **BTS**.

Daimon Lux est une plateforme web dédiée à l'**achat et à la revente de vêtements de luxe**, avec une distinction entre les **acheteurs et les revendeurs**.

**Technologies :**
- PHP
- HTML
- CSS
- MySQL

Ce projet m'a permis de mettre en pratique le développement web, la gestion d'une base de données et la création d'une application avec différents types d'utilisateurs.
